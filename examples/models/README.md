# 示例 IFC 模型

拿来即玩的 buildingSMART 官方样例，可直接上传到 viewer 体验「上传 → 转换 → 查看/编辑」全流程。

## 文件

- `wall-with-opening-and-window.ifc` — 带开洞与窗的单墙（IFC4 ReferenceView 1.2，~12 KB），与 converter 测试 fixture 同文件。
- `tessellation-with-individual-colors.ifc` — 带独立颜色三角化的最小模型（IFC4，~2.6 KB），用于验证颜色渲染。
