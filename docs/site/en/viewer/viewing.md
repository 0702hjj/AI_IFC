# Visibility, Sectioning & Measurement

## Visibility toolbar

- **Hide selected**: hide the currently selected elements.
- **Isolate**: show only the selected elements.
- **X-Ray**: render all elements semi-transparent.
- **Reset visibility**: make all elements visible again.

## Sectioning

Move the section plane with the X / Y / Z sliders to inspect the model's interior structure.

## Measurement

Distance measurement: click two points in sequence to show the distance between them; double-click to finish; measurements can be cleared.

## Other view tools

- **NavCube**: orientation indicator and view switching.
- **Reset view**: restore the default camera position.
- Orbit / zoom / pan are xeokit's default interactions.
