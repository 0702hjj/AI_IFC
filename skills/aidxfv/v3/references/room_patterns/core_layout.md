## pattern: 核心筒非矩形轮廓（住宅板式，res_3c6u_std 实测）
命中痛点: P2-1 / P2-4
适用房间: core（电梯/前室/管井群）
适用条件: {"has_core": true, "building_type": "residence", "core_form": "non_rectangular"}
案例来源: golden/residence/res_3c6u_std（三核心筒六户板式）

设计要点: 核心筒 ≠ 矩形——凸字形复合功能区：
- 北部（宽）：担架电梯+消防电梯+合用前室+加压送风井+水暖井（并排+共用管井）
- 南部（窄）：强电井+弱电井（贴筒南缘，走线到各户最短）
- 三组核心筒凸字形各异（west 8 顶点 / mid 8 顶点 / east 10 顶点——南窄部偏左/偏右不同）

决策依据: 电梯+前室+管井需并排 → 北宽；强弱电井只需狭条 → 南窄；
电井贴筒南缘走线最短；南偏左/右取决于电井相对电梯位置（每栋不同——
三核顶点数 8/8/10 各异是真实差异）。
反例: 顶点环用矩形糊弄（48㎡ vs 真实 29.7㎡）→ 误包相邻厨房；三筒同矩形 → 丢掉管井布置差异。

## pattern: 大型购物中心不规则布局（retail_mall_01 实测）
命中痛点: P2-1 / P2-4
适用房间: retail / corridor / atrium / elevator / escalator / stair
适用条件: {"building_type": "retail", "layout": "mall_with_atrium", "irregular_outline": true}
案例来源: golden/retail/retail_mall_01（195×185m 不规则七边形+中庭+分散核心筒）

设计要点（商场 vs 其他类型的根本差异）:
- 不规则外轮廓：7 顶点凸包（跟随地块，非矩形）——outline 继承 plan（D34）
- 中庭 holes：贯穿多层天井（采光+视觉焦点+动线汇聚）——holes 通用语义块（D33）
- 分散式核心筒：沿主动线分布（大进深单核不够用）
- 环廊：绕中庭 6m 步行街式走廊——corridor path 分段（edges 拼合）
- 扶梯沿主动线：引导客流从入口到深处（不靠电梯）
- 租赁线分割店铺：弹性可变（rooms 到功能分区级，不逐铺标注）
