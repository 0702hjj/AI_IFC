# 建筑类型包：商业零售（retail)

> 依据 `_template.md` 填写；规范出处本 skill 自包含。
> 素材：mall_l1 / mall_l1_v2 实战案（150m×100m，双面步行街+中庭，40 零售单元+2 主力店）。
> 状态：v0.1，经 mall_l1_v2 生成验证。

## T1 类型适用范围声明

**覆盖**：单层商业平面（购物中心/商场/商业街）的方案级平面图：矩形大跨度轮廓、步行街（双面店）+中庭拓扑、主力店+标准商铺+后勤走廊+核心筒/扶梯。

**不覆盖**：地上二层及以上的楼层平面（中庭以上）、地下车库、立面/剖面、结构与机电图、防火分区专图。遇到即 upfront 声明不适用。

**图纸集构成规则**:
| 输入条件 | 产出图 |
|---|---|
| 恒有 | L1 平面图（本包验证范围） |
| 用户给各层参数 | 各层平面图（同机构逐层生成） |
| 其他（立面/剖面/结构…） | 不出，声明超范围 |

## T3 坐标与命名约定

- 单位 **mm**;`doc.units = ezdxf.units.MM`；模型空间 1:1。
- 原点：轮廓**左下角**(x 向右沿宽，y 向后沿深），与 `rect_wall_frames` 一致。
- 外墙命名 front/rear/left/right（从街面看建筑的左右）；偏移起算：front/rear 从左端，left/right 从前端。
- 步行街两侧店墙用显式 `WallFrame`:**s 沿街向，d=0 在街面，厚度向店内**；开洞（storefront）按街墙局部 s 声明。
- 平面参数以**头部常量**声明（W/D/STREET_X0/X1/STREET_Y0/Y1/SHOP_W/SHOP_DEPTH/BOH…)，改常量即改全案（mall_l1_v2 实证）。

## T5 符号与画法规范

| 构件 | 画法（archdxf 调用） | 状态 |
|---|---|---|
| 外墙+入口 | `wall_run`(cuts=入口开洞，角部归属 front/rear)+ `jamb_pair`；方案级不画门扇 | HAVE |
| 店面幕墙 | 街墙 `wall_run`(cuts=storefront 三元组）+ `jamb_pair` + `window_line`(WINDOW)，每开间一条 | HAVE |
| 商铺分隔 | `partition_frame("y", x, …)` + `wall_run`(span=带范围，钳制到相邻墙内面） | HAVE |
| 主力店分隔 | 同上，满跨（EXT_T → D−EXT_T) | HAVE |
| 柱 | 600×600 LWPOLYLINE 方块，COLUMN 层，位于开间分点 | HAVE |
| 核心筒/扶梯 | 矩形 LWPOLYLINE + 居中标签（WALL) | HAVE |
| 中庭 | 街墙即为边界，居中大字标签；不另画填充 | HAVE |
| 玻璃地弹门/卷帘门/防火门 | 画法未定 | LATER |

实现要点：poché 必须 `set_solid_fill()`(archdxf wall_run 已内置）；审查渲染用深色背景（color 7 白底不可见）。

## T6 标注与文本规范

- **标注链**：开间链（10m 分点，街墙内侧，ARCHDXF-SM 小字 dimstyle)；总尺寸外圈（front+left 恒有，ARCHDXF 正字）。
- 标注文本：整数 mm;dimtad=1（文字线上方）;ARCHTICK tick。
- 文本全大写；字高层级见 T4。
- 入口标签 ENTRANCE 置外墙外侧，与总尺寸避让（左右入口标签距外墙 ≤6000，总尺寸再外移）。
- 区域标签居中于区域几何中心。

## T7 几何校验规则

| 检查 | 规则 | 级别 |
|---|---|---|
| 开洞拟合 | storefront/入口 `offset+宽度 ≤ 所属墙长` | 自动（错误，带字段路径） |
| 带间拟合 | 商铺带/后勤带/分隔 span 在轮廓内且钳制正确 | 自动 |
| 开间整除 | 街长应为开间整数倍，否则 upfront 提示调整 | 自动 |
| 入口宽度 | 疏散总宽度几何下限 | **BY REVIEW** |
| 店面开洞率 | 幕墙占比与消防/节能关联 | **BY REVIEW** |
| 防火分区 | 面积与分隔合规性 | **BY REVIEW** |

## T8 负能力声明

本包**不做**:
- 不自动布店/自动排开间——排布永远来自声明参数；
- 不做人流、消防疏散、防火分区计算（标 BY REVIEW);
- 不出结构/机电尺寸与选型；
- 不画中庭以上楼层、地下层、立面剖面；
- 不使用画法未定的扩展词（玻璃地弹门/卷帘门/防火门）——定了画法再用。
