# 建筑类型包模板（_template)

> 复制本文件为 `<类型名>.md` 填写。八节（T1–T8）**全部必填**,T8 留空视为不完整；规则逐条打状态标签（HAVE/ADOPT/LATER)，文末维护采纳日志。

## T0 通用设计标准（所有类型包继承，防错误设计底线）

> 检查方式三档：**自动** = 脚手架 VALIDATION ZONE 已强制（每次 gen_dxf 运行）;**半自动** = 声明层可机器比对，尚未接线；**BY REVIEW** = 语义判断，生成时自查并在图面留证。

### U-A 开洞与门位置

| 编号 | 规则 | 检查 |
|---|---|---|
| U-A1 | 开洞（门/窗）不得横跨墙交接：开洞区间不得含其他墙实体段；隔墙端头不得落在开洞上（T/十字交接处墙必须连续） | 自动（FAIL) |
| U-A2 | 墙垛净距：开洞边缘距墙端/相邻开洞边缘 ≥ 本墙厚（角部与洞口间墙体完整性） | 自动（WARN) |
| U-A3 | 门摆弧扇区不得被墙/柱/固定设备侵占 | 自动（FAIL) |
| U-A4 | 入户门/疏散门开向：默认向内，疏散方向开向由类型包 T4 声明 | BY REVIEW |
| U-A5 | 门宽不得小于类型包 T4 下限（常用值表给数） | 半自动（声明比对） |

### U-B 同层连通性

| 编号 | 规则 | 检查 |
|---|---|---|
| U-B1 | 每个房间至少一个可通行门——不允许无门封闭房间 | 半自动 + BY REVIEW |
| U-B2 | 禁止穿套：进入任何房间不须穿越另一私密房间（卧室/卫生间）；所有房间连通至同一公共交通区（起居/走道/门厅） | BY REVIEW |
| U-B3 | 多层平面交通核必须连通楼梯占位与入户门；楼梯间缺位即方案不成立 | 自动（存在性，包 T7 接线）+ BY REVIEW（路径） |
| U-B4 | 交通路径净宽 ≥ 类型包 T4 走廊宽下限 | BY REVIEW |

### U-C 房间隔离原则

| 编号 | 规则 | 检查 |
|---|---|---|
| U-C1 | 卫生间门不得直接开向厨房（卫生隔离） | BY REVIEW（门-房间邻接声明后可升级半自动） |
| U-C2 | 卧室不得以另一卧室为唯一入口（U-B2 的具体化） | BY REVIEW |
| U-C3 | 湿区（卫生间/厨房）集中布置、贴管井；强制级别由类型包声明 | BY REVIEW |
| U-C4 | 卧室宜远离楼梯间/电梯井（噪声隔离） | BY REVIEW |
| U-C5 | 公私分区：入户动线先公共（起居/餐厅）后私密（卧室） | BY REVIEW |

### U-D 结构与占位

| 编号 | 规则 | 检查 |
|---|---|---|
| U-D1 | 柱不得侵占门/窗开洞区间与门摆弧扇区 | 自动（FAIL) |
| U-D2 | 多层建筑必须为楼梯间预留跑段+平台组合占位 | 自动（存在性，包 T7 接线） |
| U-D3 | 非结构元素（洁具/家具）缺省不画；画了不得侵占门摆弧与开洞 | 自动（FAIL) |
