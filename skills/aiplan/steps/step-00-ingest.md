# step-00 摄取与归一化（P0 理解）

> plan 管线的入口：外部资料 → 意图卡片 + 缺口清单。
> （本 skill 自包含——不依赖外部设计文档，执行规范全在本 skill 内。）

## 输入

- 外部资料：图片 / PPT / 技术文档 / 用户对话原话（异构）
- 已落盘的 run 目录 `plan/<时间戳>_<项目>/`（若存在 = 中断恢复，见路由）

## 机器动作（确定性）

1. 抽取**意图卡片**：类型 / 层数 / 功能分区 / 面积 / 朝向 / 设计标准 / 特殊需求
2. 每条卡片标来源（哪份资料哪页 / 哪句原话）
3. **每条卡片标所属轮次**（本 skill 4 轮：①骨架 B0方向/A地块/B分区；②几何 C轮廓+核心筒；
  ③功能 D功能/E配比/F规范；④结构空间 G屋顶+特殊结构/H空间补充）——step-01 按轮归位消化
4. 对照 building_type 词表（§3 副本）归一化用词（卧室→bedroom）
5. 产出**硬约束缺口清单**（该有却没有的：层数、轮廓、类型……）
6. 若摄取到轮廓资料（用户给的图纸/坐标）→ 文字描述地块形状/朝向/四至（不用 ASCII 栅格，表达力不足）

## 模型动作

- 理解异构资料（图/文/表），把自然语言翻译成意图卡片
- **不臆造**——资料没说的归缺口，不猜默认

## 输出

- 意图卡片集（内存态，不落盘——D-4）
- 缺口清单
- 来源索引

## 停步条件

- 硬约束缺口未补前不进 step-01
- **本步是唯一允许空手等用户的步骤**（对齐 V2 S0）

## 路由（中断恢复，D-4）——判定逻辑只在本步讲一次

```
.venv/bin/aiplan route <workspace>
→ step-00（plan/ 下无完整 run，走完整 P0→P2）
→ step-02（有完整 run 已冻结，直进 step-02 校验，跳过 step-01）
```

判定规则（run 目录唯一性）：
- plan/ 下**无任何完整 run**（无 `<run>/plan.json + bim_supplement.json` 成对）→ 本步（P0 理解）
- plan/ 下**有完整 run**（结构完整）→ 直进 step-02 校验
- run 内文件损坏/不完整 → step-00（从头）

## 交接

缺口补齐 → step-01（渐进设计对话）
