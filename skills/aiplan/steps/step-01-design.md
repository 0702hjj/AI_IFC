# step-01 渐进设计对话（P1 设计，本 skill 核心）

> **从模糊到清晰的渐进设计**：边设计边确认，4 轮推进，可回退。
> 草案与确认不再割裂——每轮都是「起草该轮 → 确认 → 修订 → 锁定」。

## 定位

plan 阶段的核心增量是**设计判断**（为什么是这个形态、这个空间组织、这个场所策略）。
本步是设计对话：把 step-00 的意图卡片 + 缺口，通过 4 轮渐进对话收敛为**全锁定的设计草案**。

## 设计哲学 · 起草边界（内化，2026-08-11）

**模型是设计师，不是画图员**：
| 起草**设计方向**（空间概念、形态策略、场所逻辑、规模气质） |
| 用**文字/示意**表达设计意图（"中央庭院作组织中枢"） |
| 几何推迟到**第 2 轮**（设计方向确认后才画） | 

**设计思维主导，几何殿后。**

## 4 轮渐进循环（每轮：起草 → 确认 → 修订 → 锁定）

```
第 1 轮 骨架   B0 方向（类型/形态/规模/气质）+ A 地块 + B 分区    ← 连问批量
第 2 轮 几何   C 轮廓 + 核心筒                                    ← 精问（derive→pattern→golden→intent→normalize→校验）
第 3 轮 功能   D 功能构成 + E 面积配比 + F 规范要求               ← 连问批量
第 4 轮 结构空间 G 屋顶+特殊结构 + H 空间补充（space_notes）       ← 精问
```

每轮通用循环（细则见 `step-01a-rounds.md`）：
```
① 起草：按该轮内容 + step-00 意图卡片，起草该轮草案（文字/示意层面）
② 确认：回显草案（建筑师词汇，不暴露字段名）→ ask_user 弹框
③ 执行：用户说"改" → 只更新该轮 → 再问同轮（不重放已锁定轮）
④ 锁定：用户确认"对" → 该轮锁定 → 进下一轮
```

**交互分层**（节奏，细则见 `step-01a-rounds.md`）：
- **连问批量**（第 1/3 轮）：一整段草案 + **一个确认框**（options：`全部 OK，继续` / `改某项` / `我自己描述`）。**禁止**拆成多个 question 逐个弹。
- **精问**（第 2/4 轮）：几何/屋顶需校验或可视化的，单独精问（文字形态描述，不用 ASCII）。
- **直落**（不弹框）：PSET、origin/north_deg、T4 默认参数——回显带一句"psets 按类型标准默认"，用户不反对即落盘。

## 回退主干（不是边角条款，是流程主干）

正常设计是模糊→清晰→**可能回退**的迭代：

```
用户改方向（"要不改成办公吧"）→ 回第 1 轮重走骨架 → 未锁定轮按新方向重推进
用户改某轮（"轮廓要改"）→ 只回该轮 + 依赖它的后续轮（查依赖表）→ 重走
用户改已锁定轮（"层数不对"）→ 查依赖表 → 受影响的已锁定轮回显变更 + 重问
```

- **换方向** → 回第 1 轮（B0 重走），后续轮按新方向重推进
- **改某轮** → 只回该轮及依赖它的后续轮；未受影响的不打扰
- 依赖关系：骨架 ← 几何 ← 功能 ← 结构空间（后轮依赖前轮）

## 收敛条件

- 4 轮（骨架/几何/功能/结构空间）全部锁定
- 必填字段全覆盖（question 追问完所有缺口）
- must 级冲突全裁决（冲突裁决见 `step-01b-protocol.md`）

## 铁律

- **唯一合法停顿 = `ask_user` 工具**。除 ask_user 外不得结束回合等用户；
  禁止「进度旁白 / 准备跑工具 / 要继续吗」类纯叙述回合。
- **进度提示只做 question 的 header 或正文首行**（如「骨架已定，进入几何轮（2/4）」），
  不得单独发一条再等回复。
- **缺口/歧义/候选/冲突/确认/获批 → 全走 ask_user 工具弹框**（不输出纯文本让用户盲答；
  question 文本无长度限制，把完整方案/计划放进去，选项给"确认/修改"）
- **用户自由表达方案 → 对话里听**（不弹框，让用户自然说话）
- **一次只问一轮内容**：回显只含当前轮；第 2/4 轮可连续多个 question，中间不准夹叙述停顿
- **第 1 轮必须一个确认框**：方向 + 已知硬缺口（层数/地块等）并进同一问，禁止拆成两轮
- **第 1 轮硬参数一次收齐（2026-08-17）**：层数 / 地块形状尺寸 / 每层户数 / 单户面积
  是落盘必需硬参数，必须在第 1 轮确认框内问完（选项或 custom 补齐）——
  用户若只答「方向 OK」未给参数，**再补一次 GAP 问（仍在第 1 轮内），
  不得带着缺口进第 2 轮画几何**；缺口不齐 = 第 1 轮未锁
- **设计方向未确认（第 1 轮未锁）不画几何**（起草边界）
- **用户锁上一轮后**：本回合内跑完本轮机器活（derive/normalize/check 等），
  PASS 才 question；FAIL 先自改，改不动再 question
- **拓扑如实归 cad**：不假装听懂房间关系落硬约束
- **回显不暴露字段名**：用建筑师词汇
- **状态不落盘**（D-4）：意图卡片 + 已锁定轮集合都在你的对话上下文里

## 交接

4 轮全锁定 → **立即进入 step-02 生成落盘，不再问用户**（落盘是流程内动作，
不产生非必要停顿）。落盘完成后再汇报结果。
