# 建筑类型包：酒店（hotel）

## T1 适用范围
覆盖：中端/精品酒店**标准层平面**（方案级）：双内廊+居中核心筒+客房排。
不覆盖：度假酒店/公寓式酒店/超五星级套房楼。

## T2 类型词汇
| 词 | 语义 | 状态 |
|---|---|---|
| `core` | 核心筒（电梯厅/楼梯/管井/公共卫生间） | HAVE |
| `corridor` | 内廊（双内廊：南廊+北廊） | HAVE |
| `guest_room` | 客房（含卧室+卫浴） | HAVE |
| `bathroom` | 客房卫浴（靠走廊侧） | HAVE |
| `lounge` | 公共休息室（联通走廊） | HAVE |
| `elevator_lobby` | 电梯厅 | HAVE |
| `anteroom` | 合用前室 | HAVE |
| `shaft` | 管井（强电/弱电/新风） | HAVE |
| `stair` | 楼梯间 | HAVE |

## T4 默认值
| 参数 | 值 |
|---|---|
| 标准层进深 | 28~32m（双内廊+双排客房） |
| 客房开间 | 3.6~4.5m |
| 客房进深 | 7~9m（含卫浴） |
| 内廊宽 | 2000~2500mm |
| 核心筒面积占比 | 12~18% |
| 层高 | 3200~3600mm |
