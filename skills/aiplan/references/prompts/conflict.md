# conflict prompt —— 冲突裁决辅助

> 当你在对话上下文里发现 must 级冲突时，用本 prompt
> 把冲突**用人话说清楚**，请用户拍板。

## 冲突裁决模板

```
[冲突] 您说的两件事打架了：
  A: "<原话引用 a_source_quote>"
  B: "<原话引用 b_source_quote>"
  问题：<a_desc> 和 <b_desc> 没法同时满足。
  可选：
    1) <option 1>
    2) <option 2>
    3) 我自己说
  裁决是您的，我只给选项——选哪个？
```

## 铁律

- **裁决是用户的**，你不替用户悄悄取舍
- 用**原话引用**（带引号），让用户知道"我说过这话"
- 选项给具体折中（"挪核心筒"而不是"改一下"）
- 用户裁决后记入你的对话上下文（resolved_conflicts），继续对话

## 典型冲突

| 冲突 | A | B | 折中选项 |
|---|---|---|---|
| 朝向 vs 核心筒占位 | 卧室全朝南 | 核心筒占南面 | 挪核心筒 / 部分卧室不朝南 / 改布局 |
| 轮廓 vs 地块 | 楼超出红线 | 轮廓定了 | 缩轮廓 / 改退线 / 调分区 |
| 屋顶 vs 顶层功能 | 人字坡屋顶 | 顶层做露台 | 局部坡屋顶 / 取消露台 / 屋顶花园在坡下 |
