# hole_patterns —— 中庭 / 天井 · 金例吸收版

## pattern: holes_courtyard（外环内孔洞）

**适用**: 商场中庭、围合庭院——贯穿多层的真实孔洞。
**要点**: `rings[].holes[]` 与外环同为 `edges` 四边（也以多点凹凸为基底——中庭常
带天窗台/扶梯缺口/挑空错位）；孔洞必须被外环覆盖，否则 `hole_outside_outer`。
多中庭 = holes 多项。

```json
"holes": [{
  "edges": {
    "west":  [[50709, 80172], [50709, 140172]],
    "north": [[50709, 140172], [90000, 140172], [90000, 130000], [110709, 130000], [110709, 140172]],
    "east":  [[110709, 140172], [110709, 80172]],
    "south": [[110709, 80172], [70000, 80172], [70000, 95000], [50709, 95000], [50709, 80172]]
  }
}]
```

金例：`retail/retail_mall_01`（单中庭 60×60m）、`retail/retail_wanda_std`（双中庭 = holes 两项）。
**反例**: 把另一套坐标系的中庭坐标塞进未对齐的外环；把中庭当 blocks 而非 holes
（孔洞是穿透，不是分区）。
