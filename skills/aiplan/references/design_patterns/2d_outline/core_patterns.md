# core_patterns —— 核心筒 · 金例吸收版

> 核心筒也是真实形态——住宅核筒常常是凸字形/切角（井道/前室组合），用多顶点折线表达。
> 模型写 core 前对照金例真实核筒坐标。

## pattern: multi_core_rings（多核数组）

**适用**: 并排双核/三核（住宅单元、商场分散核）。
**要点**: `core` 为数组，每项 `{id, path:{rings:[{edges}]}}`；无核（独栋）省略。
**反例**: 三核只写一个 path，信息丢失。

金例：`res_2s4u_std`（2）、`res_3c6u_std`（3）、`retail_mall_01`（2）、`retail_wanda_std`（3）。

---

## pattern: convex_core_path（非矩形核筒）

**适用**: 住宅凸字形核（南窄北宽——电梯+前室+管井组合，南缘只贴井道）。
**要点**: 核也用 `edges` 折线——**south 边多顶点画凸出/收窄**，形态跟随内部功能组合。

```json
"core": [{"id": "west", "path": {"rings": [{"edges": {
  "west":  [[6230, 8464], [6230, 12342]],
  "north": [[6230, 12342], [12170, 12342]],
  "east":  [[12170, 12342], [12170, 8464]],
  "south": [[12170, 8464], [10951, 8464], [10951, 5240], [8001, 5240], [8001, 8464], [6230, 8464]]
}}]}}]
```

金例：`residence/res_3c6u_std` 三个凸字核（8 顶点）——北宽 5.94m（电梯+前室并排）、
南窄 2.94m（只贴强弱电井），**南缘中部 2 个凸出点表达井道收窄**。
`res_2s4u_std` 双核：west 2.6×3.5m、east 2.6×2.5m（纯楼梯核，尺寸各异——如实写真实尺寸）。

**教学要点**：
- 核筒形态跟随**内部功能组合**：电梯+前室+管井并排 → 北宽；单井道 → 南窄
- 凸出点 = 井道/前室的位置痕迹——写核筒时先想"里面放了什么"，不是画个框
- **反例**: 只给包围框（丢掉井道布置差异——res_3c6u 三核凸字各异是真实差异）
