# form_patterns —— 外轮廓（rings.edges）· 金例吸收版

> 本文件是从金例 design_intent 吸收的**真实轮廓画法**——每个 pattern 带金例真实坐标，
> 模型写 intent 时照此组织形态（不是凭空想，是学金例怎么表达真实地块）。
> 协议语法见 design_intent.schema.json（edges 四边拼合 + 角点共享）。

## pattern: edges_four_sides（四边拼合）

**适用**: 所有 zone 外轮廓。**形态由地块与户型决定——每条边都承载真实凹凸**。
**要点**: 东南西北各一条折线，顶点数跟随真实轮廓——斜墙、切角、核筒凸出、天井凹凸
**全部写进对应边的多顶点**；normalize 拼 `west + north[1:] + east[1:] + south[1:]` 去闭合点。

```json
"form": {"path": {"rings": [{"edges": {
  "west":  [[0, 724], [1700, 1500], [1700, 6200], [1092, 12711]],  // 贴西边核筒凸出 + 台阶
  "north": [[1092, 12711], [13773, 11868], [17371, 13174], [22880, 15680],
            [24931, 16178], [29875, 14868], [42943, 15681], [44043, 14665]],  // 核筒凸出折
  "east":  [[44043, 14665], [42860, 3523]],      // 大切角（东北角削掉 1.2m）
  "south": [[42860, 3523], [27146, 3817], [19284, 0], [13989, 990],
            [19239, 2299], [19010, 5681], [17100, 8225], [13883, 8586],
            [10997, 4751], [12169, 1074], [9146, 963], [10729, 2609],
            [10545, 5671], [7494, 8680], [4519, 8111], [2351, 2654],
            [4062, 1051], [6759, 876], [0, 724]]  // 户型凹凸：天井/阳台/入口
}}]}}
```

金例：`residence/res_2s4u_std`（总 32 顶点——南边 19 点表达户型的阳台凹凸与天井，
北边 9 点表达核筒凸出；这是**真实户型轮廓**的形态密度——多点凹凸是默认画法）。

**教学要点（多点凹凸是默认画法，不是特例）**：
- **四条边都以多顶点凹凸为基底**——west 也带贴边核筒凸出 + 台阶（`[0,724]→[1700,1500]→[1700,6200]`）
- 每户南向阳台凸出 → 2 点凸出（如 `[17100,8225]→[13883,8586]`）
- 户间天井/凹口 → 折回点（如 `[13989,990]→[19239,2299]`）
- 入口/门廊 → 局部凹（如 `[6759,876]→[0,724]`）
- **轮廓的凹凸数 = 户型策略的几何痕迹**——模型声明户型策略（阳台/天井/错位）后，
  轮廓必须把这些痕迹画出来——凹凸直接写在边顶点上，不做装饰性贴补
- **判定**：写完数顶点——只有某条边是 2 点直线（非斜墙）＝那条边没表达户型，补凹凸

**反例**: 各边仅 2 点（= 没表达任何户型策略，南边只剩两个角点）；`outer.base`；角点不共享导致自交。

## pattern: irregular_edge_polyline（边内大折）

**适用**: 斜墙、切角、地块异形边——**边本身不是直线**，用多顶点折线表达。
**要点**: 大折写在对应 `edges.*` 多顶点上；**规则凸出**（阳台带/核筒外凸）走
`segment_patterns` 的 projection，不要重复画进边。
**反例**: 边仅 2 点直线 + 用 segments 冒充斜墙/切角（斜墙/切角是边的多顶点形态，不在 segments）。

```json
"west":  [[0, 724], [1092, 12711]],     // 整条西边是斜墙（西南角 724 → 西北角 12711）
"east":  [[44043, 14665], [42860, 3523]],  // 东北大切角：y 从 14.7m 削到 3.5m
"south": [[42860, 3523], [27146, 3817], [19284, 0], [13989, 990], [0, 724]]
```

金例：`residence/res_2s4u_std`（斜墙 west + 大切角 east + 户型凹凸 south）、
`retail/retail_wanda_*`（商场异形边）。

**教学要点**：斜墙/切角是**真实地块或建筑形体**的直接结果——地块斜边、退台削角、
转角幕墙。写 intent 前读地块四至（step-01a A 轮），斜边如实写，不拉直。

## pattern: multi_rings_same_zone（同 zone 多分区）

**适用**: 主屋+露台等**相互独立、不相交**的封闭轮廓（同一 zone 多个体量）。
**要点**: `rings` 数组，每个 ring 独立四边；normalize → `outline_mm` 多块。
**反例**: 用假凹口把不相连体量硬连成一个环（露台不该是主屋的凹）。

金例：`single_family/floorplan_structure`——L 形主屋 ring + 独立露台 ring（2 块）。
