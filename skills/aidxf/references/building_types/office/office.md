# 建筑类型包：办公写字楼（office)

> 依据 `_template.md` 填写；规范出处本 skill 自包含。
> 状态：v0.1，**尚未经生成用例验证**（验证案：标准层平面）。

## T1 类型适用范围声明

**覆盖**：多层/高层办公楼的**标准层平面**（方案级）：核心筒 + 周边办公区拓扑，开敞办公/单元办公/走廊式布局，柱网表达。

**不覆盖**：超高层专项（避难层、擦窗机等）、地下车库、裙房商业（属 retail 包）、立面/剖面、结构与机电图、精装深化。遇到即 upfront 声明不适用。

**图纸集构成规则**:
| 输入条件 | 产出图 |
|---|---|
| 恒有 | 标准层平面图 |
| 用户给首层/其他层差异参数 | 对应层平面图（同机构逐层生成） |
| 立面/剖面/结构/机电 | 不出，声明超范围 |

## T3 坐标与命名约定

- 单位 **mm**；模型空间 1:1；原点轮廓左下角。
- 外墙命名 front/rear/left/right；偏移起算同 vocabulary。
- 柱网：以**轴号**命名（数字轴 1,2,3… 沿 x，字母轴 A,B,C… 沿 y)，柱位于轴交点；开洞/分隔尽量对齐柱网轴线声明。
- 平面参数头部常量化（W/D/GRID_X/GRID_Y/CORE_W/CORE_D/CORRIDOR_W…)，改常量即改全案。

## T5 符号与画法规范

| 构件 | 画法（archdxf 调用） | 状态 |
|---|---|---|
| 核心筒 | `partition_frame`+`wall_run` 矩形围合，内部电梯/卫生间以分隔+标签表达，楼梯用 stair-flight/landing 组合（见下行） | HAVE（围合+标签） |
| 柱网 | 轴交点 700×700 方块 COLUMN;**轴号**:TEXT 圆+字（数字轴下缘、字母轴左缘） | HAVE |
| 幕墙外墙 | `wall_run`(cuts=落地窗带）+ `window_line`(WINDOW)+ 单元竖梃线（1500 模数） | HAVE（方案级） |
| 办公室/会议室分隔 | `partition_frame`+`wall_run`(cuts=门洞）+ `door_leaf`(swing 向走廊内开须避让——`out-*` 朝房间侧） | HAVE |
| 电梯厅 | 核心筒正面开敞区+标签；电梯门洞在核心筒墙声明 | HAVE |
| 楼梯 | `stairs.draw_stair_flight`（踏步线+折断线+UP/DN 箭头）+ `draw_landing` 组合；**标准层必须预留楼梯间占位**（双跑示例见 archdxf_api §4b) | HAVE |
| 卫生间洁具 | `fixtures.draw_fixture`(toilet/lavatory 等通用词） | HAVE |

实现要点：办公室门开向走廊侧须查消防（疏散方向）——方案级统一 `out-*`（向房间内开）或按用户声明，**疏散方向合规标 BY REVIEW**。

## T6 标注与文本规范

- **标注链**：柱网轴间距链（下缘+左缘，沿轴号）→ 总尺寸外圈；核心筒定位尺寸（至最近外墙）。
- 轴号体系：数字轴下缘、字母轴左缘，圆+字，DASHED 轴线穿建筑。
- 标注文本整数 mm;ARCHTICK；文本全大写。
- 房间标签：名称+（可选）面积小字；开敞办公区只标名称。
- 区域标签层级：区域 2500 / 核心筒内小房间 1200 / 层标题 5000。

## T7 几何校验规则

| 检查 | 规则 | 级别 |
|---|---|---|
| 开洞拟合 | `offset+宽度 ≤ 墙长`（含核心筒墙） | 自动（错误，带字段路径） |
| 柱网整除 | 轮廓尺寸应为柱网模数整数倍（或余量明确声明为边跨） | 自动（警告） |
| 走道宽度下限 | 双侧布房内走道 ≥ 1800（几何量） | 自动（几何下限） |
| 核心筒占比 | 核心筒面积/标准层面积 20–25% 区间提示 | 自动（提示） |
| 楼梯占位 | 多层平面必须有 stair-flight 声明（缺位=方案不成立） | 自动（错误） |
| 疏散距离/宽度 | 与用途、人数相关 | **BY REVIEW** |
| 无障碍 | 电梯/走道/卫生间合规 | **BY REVIEW** |
| 公摊率/得房率 | 经济性指标 | **BY REVIEW** |

## T8 负能力声明

本包**不做**:
- 不自动布核心筒、不自动分办公室——位置与划分永远来自声明；
- 不做疏散计算、垂直交通（电梯数量/候梯时间）计算、人流分析（标 BY REVIEW);
- 不出结构（柱截面实为结构选型，方案级仅占位）与机电内容；
- 不画幕墙节点、卫生间大样等深化图域内容（超范围）;
- 不使用画法未定的扩展词（防火门/管井门/避难层）——定了画法再用。
