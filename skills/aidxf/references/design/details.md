## 角色

本文件是 S3 细节设计规范。主 agent 处理每个 zone 时加载本文件（含上方 include 链），
做最后一步细节批处理：门窗（统一规律）+ 柱网 + 标注。

## 门窗统一规律（批量套用）

> 按下列规律给整层批量生成门窗。尺寸取类型包惯例；类型包没写的用常见值
> （住宅内门约 855~900mm、办公门约 1000mm）。

### 门——树形分层连通

门是**树形分层**组织，层次自上而下：**核心筒（根）→ 走廊 → 小分区 → 具体房间**。
每层门挂向上一层，连通路径逐级成立，从根到任意房间可达（图连通）。

```
核心筒（根：楼梯/电梯/前室，竖向交通入口）
   │ 核心筒门——筒内房间开向走廊/前室
走廊（水平交通主干）
   │ 分区门——走廊与分区之间的门（有分区的层）
小分区（分区内公共空间）
   │ 房间门——每房间 1 扇，开向分区内/走廊
具体房间（叶节点）
```

1. **核心筒门**：筒内房间（楼梯间/电梯厅/前室/管井）门开向**走廊或前室**——
   竖向交通接入水平交通的根节点
2. **分区门**：分区与走廊之间的门（分区有独立入口时），分区内房间经它连通走廊
3. **房间门**：每房间 1 扇，挂**公共区侧**的墙——优先共享墙（该墙也在邻居/
   走廊的 boundary_walls 里）；独立房挂入口墙。门向当前层次开放，swing 朝房间内开
4. **沿墙位置**：墙段中点（along = length_m/2）；门宽放不下就退避留门垛
5. **画法**：`door(msp, wall_key, at_or_along, width_mm, swing)`——墙 key + 沿墙距离，坐标机器算
6. **连通性自查**：从核心筒出发沿门链到每个房间可达（树形无断支）；断链房间补门
7. 尺寸/门型按类型包惯例（如住宅内门 900、大门 1000；办公玻璃门；商铺大开门）

**门避让**：
- 门与窗同墙时错开（门沿墙位置避开窗洞区间，中间留墙垛）
- 门扇（leaf + swing 弧）扫过范围无窗、无相邻门扇——相邻门 swing 相向开时对向错位
- 门宽沿墙放得下；放不下退避留门垛，门扇范围随之后移

### 窗——外墙为主，内窗为辅

1. **外墙窗（主体）**：朝建筑外开窗——房间有 frontage 声明 → 在 frontage 方位的
   外墙段开窗（boundary_walls 里 `is_exterior=true` 且 `azimuth` 匹配）；无 frontage
   的采光房选南/东外墙；无采光房（贮藏/卫生间/楼梯间/机房）外墙不开窗
2. **内窗（少数）**：内部开窗——天井/中庭侧内墙、管井检修窗、相邻功能间采光井等，
   按类型包规范判定；内窗不占外墙采光
3. **沿墙位置**：外墙段中点（`p0_mm`/`p1_mm` 已给坐标，中点即窗中心）
4. **画法**：`window(msp, wall_key, at_or_along, width_mm)`——外墙边界段可直接用
   段中点绝对坐标画，或先 wall_run 注册再沿墙定位
5. 尺寸按类型包惯例（窗宽 ≈ 面宽减两侧墙垛）

**窗避让**：窗洞区间避开同墙门洞（门扇扫过范围）；窗与窗相邻留墙垛。

### 特殊

- 楼梯间/机房按类型包规范设门（防火门等构件标记）
- placemark 房（stair/elevator 标签房）不画实体门
- 卫生间高窗（sill 抬高）等按类型包

## 柱网

结构柱贴**分区边界交点 + 骨架轮廓转角**（normalize 产物分区多边形拿交点）；
柱截面按类型包惯例；核心筒剪力墙侧不画柱。

## 标注

房间名 + 面积（`tag`，位置 = labels 的 at 点）；外墙总长 + 开间分格尺寸链
（`draw_dim_chain`）；特殊门（防火/入口）单标。

## 边界

- 房间划分保持原样（改墙位置/增删分墙 → reconcile 对账 error）
- 骨架（core/corridor/main_partitions/blocks）保持原样
- 门窗批量规律生成，特殊处按类型包自行决断
- 工作范围限本层

## 建造

1. 在 `floor.dxf` 上逐构件增量画（`aidxfv3 draw`）——门 `door(...)`、窗 `window(...)`、
   柱 `draw_column(...)`、标注 `tag/draw_dim_chain(...)`
2. `aidxfv3 svg` 自检 → `aidxfv3 check` → `aidxfv3 readback` + `aidxfv3 reconcile`
3. readback 产物含 `doorwin_issues`（门窗碰撞：门扇扫窗 / 相邻门 swing 重叠）——
   非空即碰撞，按避让规则修正后重跑 readback
4. 完成记录一行摘要（门/窗/柱/标注点数 + 校验结论 + 文件指针）
